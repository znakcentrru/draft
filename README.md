# Драфт-подсказчик для ранкеда Brawl Stars

Веб-страница, которая подсказывает, кого брать и кого банить в драфте ранкеда. Учитывает режим и карту, тир бравлера в текущей мете, контрпики к вражеским пикам, связки с уже взятыми союзниками, баланс классов в команде и очередь пика (1-2-2-1). Свежая статистика ранкеда уровня Легенда+ собирается автоматически 4 раза в сутки.

Сайт работает целиком в браузере, без сервера и сборки: это один файл `index.html`. Статистику собирает GitHub Actions скриптом `scripts/update_stats.py` и кладёт в ветку `data`, откуда её загружает сайт.

## Запуск

- Локально: просто откройте `index.html` в браузере.
- Онлайн через GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch**, выберите ветку `main` и папку `/ (root)`. Через минуту страница появится по адресу https://znakcentrru.github.io/draft/.

## Как пользоваться

1. Выберите режим и карту.
2. Отметьте, кто пикает первым.
3. Вносите баны и пики по ходу драфта. Быстрее всего — через поле «Быстрый ввод»: наберите первые буквы имени (можно по-русски, по-английски или в английской раскладке вместо русской) и нажмите Enter или плитку. Бравлер встанет в нужный слот сам: сначала баны, потом пики по очереди 1-2-2-1. Кнопками «Бан», «Мы», «Враги» можно выбрать слот вручную.
4. Во вкладках «Кого брать» и «Кого банить» появятся советы с пояснениями. Нажатие на совет ставит бравлера в следующий слот.

## Аномальные бойцы и разбор бойца

Для каждого бойца, у которого набралось хотя бы 300 матчей на Легенде+, скрипт считает разбор:

- **кого бьёт и кого боится** — по особенности пары: фактический винрейт минус ожидаемый по общей силе обоих (так видно настоящие контрпики, а не просто сильных бойцов);
- **на каких картах и в каких режимах** он сильнее или слабее своего среднего;
- **винрейт с поправкой на соперников** — каким он был бы против обычного состава, а не против тех, под кого его берут;
- **средний ранг игроков** на нём — видно, раскрывается ли он в руках сильных игроков.

Признаки аномальности (относительно остальных бойцов): очень высокий или низкий винрейт, «сильнее, чем кажется» (берут редко, выигрывает часто), «переоценён» (берут очень часто, выигрывает реже половины), «ситуативный» (сильный разброс по соперникам), «зависит от карты», «для сильных игроков», «удобные соперники».

На сайте: раздел «Аномальные бойцы» с фильтром по признакам и карточка бойца — открывается из этого раздела и кнопкой «i» у любого совета. Из карточки бойца можно сразу поставить в пик или бан.

## Сильные связки

Скрипт считает, как выигрывают пары и тройки бойцов **в одной команде** (пары — от 60 матчей вместе, тройки — от 30). Главное — синергия: насколько связка выигрывает чаще, чем ожидалось бы по силе каждого бойца (для пары ожидание = винрейт A + винрейт B − 50%, для тройки — сумма трёх минус 100%). Так просто сильные бойцы не выдаются за сильную связку.

На сайте:

- раздел «Сильные связки» — вкладки «Пары», «Тройки» и «Популярные тройки»;
- советы учитывают уже взятых союзников: «+ Брок в команде: 58% побед вместе», а для третьего пика — «+ тройка Брок + Гас + он: …»;
- в карточке бойца — лучшие напарники, с кем он сочетается плохо, и лучшие тройки с ним.

## Разбор игрока по тегу

Сайт статичный, а ключ API секретный, поэтому матчи собираются заранее — для тегов из файла [`players.txt`](players.txt).

**Добавить игрока с сайта.** Введите тег в «Разборе игрока». Если его ещё нет в списке, появится кнопка «Добавить в отслеживание»: она открывает на GitHub готовую заявку (issue «Отслеживать игрока #ТЕГ»), остаётся нажать «Create» — нужен аккаунт GitHub. Сценарий `.github/workflows/add-player.yml` (скрипт `scripts/add_player.py`) берёт из заявки только тег из допустимых символов, проверяет через API, что игрок существует, дописывает его в `players.txt`, сразу запускает короткий сбор, отвечает в заявке и закрывает её. Через 5–10 минут игрок появляется на сайте. В списке не больше 300 игроков (`BS_MAX_TRACKED`).

**Вручную.** Откройте `players.txt` на GitHub, допишите строку с тегом (`#CU000VU2` или `CU000VU2`) и сохраните — игрок появится после ближайшего планового сбора. Строки, начинающиеся с «# » (решётка и пробел), — комментарии.

При каждом сборе (4 раза в сутки) скрипт забирает **все бои 3 на 3 в основных режимах** — и ранкед, и обычные (трофейные) — и **копит историю** до 800 последних боёв, хотя сам API хранит только 25. Фильтра по званию в личном разборе нет. Результат лежит в ветке `data`, в `players/<ТЕГ>.json`. На сайте в разделе «Разбор игрока» вводите тег и видите:

- сколько матчей, процент побед, ранг сейчас и лучший ранг в истории;
- переключатель «Все / Ранкед / Обычные»;
- своих бойцов: бои, победы и разницу со средним винрейтом этого бойца в ранкеде по всем рангам;
- против кого тяжелее и легче всего, результаты по режимам;
- разбор последних боёв; для боёв в ранкеде — оценку вашего пика против вражеского состава (по статистике ранкеда всех рангов: сила бойца, результаты против этих врагов, связки с этими союзниками) и кого можно было взять сильнее. Вердикт — по месту пика среди всех вариантов: «отличный» — среди 10% лучших, «нормальный» — среди 30%. В обычных боях пикают вслепую, поэтому пик там не оценивается;
- «стоит попробовать» — бойцов, которые чаще всего были бы сильнее вашего пика.

Сводку (бойцы, соперники, режимы, «стоит попробовать») сайт считает сам из списка боёв, поэтому она пересчитывается под выбранный фильтр. Колонка «К среднему в ранкеде» — ваш процент побед на бойце в ранкеде (от 5 боёв) минус его средний процент побед в ранкеде по всем рангам.

Оценка пика — задним числом: при пике вы могли ещё не знать всех врагов, а лучшие варианты могли быть забанены (баны и порядок пиков API не отдаёт).

## Окно поверх игры (ПК)

Кнопка «Поверх игры» под заголовком открывает драфт в отдельном маленьком окне, которое остаётся поверх всех остальных: можно нажимать в игре, а окно не пропадает. В окне — состав с быстрым вводом, советы, режим и карта, окно выбора бравлера и карточка бойца; горячие клавиши работают и там. Закрыли окно (или нажали «Вернуть на страницу») — всё возвращается на сайт.

Работает в Chrome и Edge на компьютере (технология Document Picture-in-Picture). В других браузерах окно браузера можно закрепить поверх игры средствами системы — в Windows это делает PowerToys (Win+Ctrl+T). Если игра запущена в полноэкранном режиме, окно может прятаться под ней — переключите игру в оконный режим или «окно без рамки».

## На компьютере

На широком экране (от 1100 пикселей) страница раскладывается в три колонки: слева режим и карта, в центре состав команд с полоской очерёдности 1-2-2-1, справа сразу оба списка — «Кого брать» и «Кого банить». Колонки с режимом и советами не уезжают при прокрутке.

Горячие клавиши:

| Клавиши | Что делают |
|---|---|
| любые буквы | начинают быстрый ввод, даже если поле не выбрано |
| ← → ↑ ↓ | выбор плитки в результатах |
| Enter | поставить выбранного бравлера |
| Esc | очистить поле или закрыть окно |
| Alt + 1…8 | взять совет из «Кого брать» |
| Alt + Shift + 1…8 | забанить совет из «Кого банить» |
| Ctrl + Z | отменить последнее действие (есть и кнопка «Отменить») |
| F2 | куда ставить: Авто → Бан → Мы → Враги |

## Автообновление

Четыре раза в сутки (по расписанию в 03:17, 09:17, 15:17 и 21:17 по Москве; GitHub при нагрузке запускает с задержкой до часа) GitHub Actions запускает `scripts/update_stats.py`. История боёв в API хранит только 25 последних матчей игрока, поэтому частые запуски дают больше данных; повторы отсеиваются. Скрипт:

1. берёт через официальный API Brawl Stars топ-200 игроков из 16 стран;
2. скачивает их последние матчи и оставляет только ранкед уровня **Легенда и выше**: средний ранг шести игроков матча не ниже Легенды I. В истории боёв у каждого игрока в матче ранкеда указан номер ранга (поле `brawler.trophies`: 1–3 Бронза, …, 16–18 Легенда, 19–21 Мастер, 22 Про). Порог можно поменять переменной `BS_MIN_RANK`;
3. затем опрашивает их соперников и союзников по матчам от Мифика и выше, потом соперников тех — и так до 20 000 игроков или 20 минут. API хранит только 25 последних боёв игрока, но у тех, кто играет реже топов, они растягиваются на несколько дней, так набираются матчи за всю последнюю неделю;
4. копит сводки за 7 дней (всё старше само выпадает) и считает винрейт и популярность бравлеров, текущий пул карт (на чём играли за последнюю неделю), а также силу в режимах, контрпики и лучших на каждой карте. Последние три — по «приросту»: насколько бравлер в этой ситуации выигрывает чаще, чем обычно, иначе просто сильный бравлер оказывался бы контрпиком ко всем;
5. сохраняет результат в ветку `data`: `meta.json` (статистика Легенды+ для сайта), `meta_all.json` (все ранги), `players/<ТЕГ>.json` (истории отслеживаемых игроков) и дневные сводки. В ветке всегда один коммит, история `main` не засоряется. Если ветку `data` не удалось прочитать, сбор прерывается, чтобы не затереть накопленное.

Для советов под конкретный вражеский пик в `meta.json` выгружаются результаты всех пар «бравлер против бравлера», где набралось хотя бы 40 матчей. Сайт считает особенность пары: фактический винрейт минус ожидаемый по общей силе обоих (если X в среднем выигрывает 60%, а Y — 52%, то X против Y ожидаемо выигрывает около 58%; если на деле 61%, у пары +3%). Так просто сильный бравлер не выдаётся за контрпик ко всем. Ещё считается средний ранг игроков на каждом бравлере — видно, кто его берёт.

Параллельно копится такая же статистика по всем рангам без фильтра (`days_all`, `meta_all.json`) — она нужна для личного разбора игроков. Учтите: обход идёт в основном по сильным игрокам, поэтому и «все ранги» — это в основном матчи от Мифика и выше.

Сайт при открытии загружает `meta.json` и смешивает свежие данные со встроенной базой: вес статистики в тире растёт с числом матчей бравлера (150 матчей — около 27%, 400 — 50%, но не больше 75%); статистика — это винрейт с поправкой на популярность, пул карт берётся из статистики, контрпики и сильные на карте объединяются со встроенными. Пока всего матчей меньше 300, статистика не используется. Если файла нет или он не загрузился, работает встроенная база. Под заголовком страницы видно, когда данные обновились, — там же их можно выключить.

### Что нужно сделать один раз

API Supercell требует ключ, привязанный к IP-адресу. У GitHub Actions адреса меняются, поэтому запросы идут через бесплатный прокси RoyaleAPI с постоянным адресом.

1. Зайдите на https://developer.brawlstars.com, зарегистрируйтесь и откройте **My Account → Create New Key**.
2. Название и описание — любые. В поле **Allowed IP Addresses** укажите `45.79.218.79` (это адрес прокси RoyaleAPI).
3. Скопируйте получившийся ключ (длинная строка, начинается с `eyJ`).
4. В репозитории откройте **Settings → Secrets and variables → Actions → New repository secret**. Name: `BS_API_KEY`, Secret: ключ. Сохраните.
5. Откройте **Actions → Обновление статистики → Run workflow**, чтобы не ждать следующего запуска. Через 3–5 минут появится ветка `data`, а на сайте — строка «Статистика ранкеда — обновлена…».

Первые дни данных мало, поэтому тиры могут скакать; через неделю-две статистика устоится.

Запустить вручную у себя: `BS_API_KEY=... python3 scripts/update_stats.py --state stats` (с вашего IP — тогда в ключе укажите свой адрес и задайте `BS_API_URL=https://api.brawlstars.com/v1`).

## Обновление меты

База бравлеров лежит в `index.html` в константе `DEFAULT_DB`. Формат строки:

```
Имя / английское имя | класс | тир | режимы | кто контрит
```

- Классы: `Т` танк, `Д` урон, `М` снайпер, `А` метатель, `К` контроль, `У` убийца, `П` поддержка.
- Тир: `S`, `A`, `B`, `C`, `D`.
- Режимы: `G` захват кристаллов, `B` броулбол, `H` ограбление, `Y` награда за поимку, `K` нокаут, `Z` горячая зона.
- Контрпики пишутся через запятую русскими именами, как в игре; английские тоже понимаются.

Базу можно править и прямо на странице, в разделе «База бравлеров». Такие правки сохраняются только в вашем браузере. Чтобы они попали в репозиторий, скопируйте текст оттуда в `DEFAULT_DB`.

## Карты

Список карт лежит в `index.html` в константе `DEFAULT_MAPS`. Формат строки:

```
Название / английское название | режим | особенности | кто силён
```

- Особенности: `открытая` (выгодно снайперам), `стены` (метателям), `кусты` (убийцам и танкам), `тесная` (ближнему бою).
- Строки, которые начинаются с `#`, считаются комментариями.

Карты ранкеда меняются каждый сезон. Список можно поправить прямо на странице, в разделе «База карт».

## Названия

Имена бравлеров, карт и режимов — как в русской версии игры (сверено с русской вики Brawl Stars). Английские названия оставлены в базе после косой черты: по ним работает поиск и их проще сверять с сайтами статистики.

## Данные

Встроенная база (запасной вариант и основа, с которой смешивается свежая статистика) — мета на 3 ноября 2026, сведённая из нескольких источников: BrawlQR, Brawl Planet, Brawl Metrics, Timesaver, Dexerto, Brawl Time Ninja (тиры); Brawlio и Trophy Coach (контрпики и режимы); Pocket Tactics (классы); пул карт — Timesaver (конец сентября 2026). Ссылки есть на самой странице в разделе «Откуда данные».

Это фанатский инструмент, не связанный с Supercell. Он только подсказывает и никак не взаимодействует с игрой.
